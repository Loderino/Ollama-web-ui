# Ollama Web UI

Веб-интерфейс для Ollama с поддержкой чатов, истории переписок и подключения моделей прямо из UI.

## Идея проекта

Проект решает главную проблему прямого использования Ollama — блокировку запросов. Когда несколько пользователей одновременно отправляют промпты, Ollama обрабатывает их последовательно, и все остальные ждут.

### Ключевые возможности

- Чаты и история переписок (хранение в PostgreSQL).
- Отправка промптов через очередь — UI не блокируется.
- Подключение других моделей Ollama прямо из интерфейса.
- Асинхронная обработка запросов через Celery + RabbitMQ.

### Стек

- **Бэкенд**: FastAPI, Celery, RabbitMQ
- **БД**: PostgreSQL + SQLAlchemy + Alembic
- **Фронтенд**: React + Next.js (App Router)
